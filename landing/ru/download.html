Скачать Translator Overlay

Установщик для Windows 10 и 11, 64 бита. Бесплатно, без учётной записи и без прав администратора.

Скачать для WindowsПоследний релиз на GitHub

Файл называется TranslatorOverlay-Setup-<версия>.exe. Все версии: Релизы.

Системные требования

  • Windows 10 или 11, 64 бита. Для всех функций нужна Windows 10 версии 2004 или новее.
  • Видеокарта не нужна. OCR использует любую видеокарту с DirectX 12 (NVIDIA, AMD, Intel) и сам переходит на процессор. Видеокарта NVIDIA с CUDA 12 лишь ускоряет необязательную локальную модель.
  • Интернет нужен для облачных режимов перевода, для загрузки модели OCR при первом запуске (около 8 МБ) и для необязательной локальной модели (около 620 МБ). С локальной моделью сам перевод сети не требует.
  • Установка для текущего пользователя без прав администратора или для всех пользователей, если выбрать это на первой странице.

Для Linux и macOS не подходит. Запуск из исходников описан в руководстве по установке (на английском).

SmartScreen пишет «Windows защитила ваш компьютер»

Честно: установщик пока не подписан сертификатом. Поэтому Windows считает каждый новый релиз файлом от неизвестного издателя, а некоторые антивирусы дополнительно ругаются на приложение из-за глобального перехватчика клавиатуры (так горячие клавиши работают в любом окне). Пока подписи нет, довериться загрузке помогает проверка SHA-256 ниже.

  1. Проверьте SHA-256 файла, как показано ниже.
  2. В окне SmartScreen нажмите Подробнее.
  3. Нажмите Выполнить в любом случае.

Если антивирус отправил приложение в карантин, восстановите его и добавьте папку установки в исключения или запустите из исходников.

Проверка загрузки (SHA-256)

SHA-256 установщика указан в описании каждого релиза. Сравните его с контрольной суммой вашего файла в PowerShell:

Get-FileHash .\TranslatorOverlay-Setup-<версия>.exe -Algorithm SHA256

Замените <версия> на версию из имени файла. Значение Hash должно совпадать с указанным в описании релиза. Если оно отличается, не запускайте файл и создайте issue.

Встроенное обновление само проверяет SHA-256 нового установщика перед установкой.

После установки

  1. Мастер первого запуска спросит, как переводить: онлайн без ключа, LLM с вашим ключом или офлайн (скачает локальную модель).
  2. Нажмите Ctrl+Shift+R и выделите любой текст. Настройки открываются по Ctrl+Shift+O.
  3. При удалении остаётся папка %APPDATA%\translator-overlay\ (настройки, история, скачанные модели); удалите её, чтобы убрать всё.
