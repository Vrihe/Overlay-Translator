Download Translator Overlay

The installer for Windows 10 and 11, 64-bit. Free, no account, no administrator rights needed.

Download for WindowsLatest release on GitHub

The file is named TranslatorOverlay-Setup-<version>.exe. All versions: Releases.

System requirements

  • Windows 10 or 11, 64-bit. Windows 10 version 2004 or newer is needed for all features.
  • No GPU required. OCR uses any DirectX 12 GPU (NVIDIA, AMD, Intel) and falls back to the CPU by itself. An NVIDIA GPU with CUDA 12 only speeds up the optional local model.
  • Internet for the cloud translation modes, for the first-launch OCR model download (about 8 MB) and for the optional local model (about 620 MB). With the local model, translation itself needs no network.
  • Installs for the current user without administrator rights, or for all users if you choose so on the first page.

Not for Linux or macOS. Running from source is described in the installation guide.

SmartScreen says "Windows protected your PC"

Honest note: the installer is not code-signed yet. Windows therefore treats every new release as an unknown publisher, and some antivirus programs also flag the app because it installs a global keyboard hook (that is how the hotkeys work in any window). Until it is signed, the way to trust a download is to check its SHA-256 below.

  1. Check the SHA-256 of the file as shown below.
  2. In the SmartScreen window click More info.
  3. Click Run anyway.

If your antivirus quarantines the app, restore it and add an exception for the install folder, or run it from source.

Verify the download (SHA-256)

The SHA-256 of the installer is in the release notes of every release. Compare it with the checksum of your file in PowerShell:

Get-FileHash .\TranslatorOverlay-Setup-<version>.exe -Algorithm SHA256

Replace <version> with the version in the file name. The Hash value must be the same as in the release notes. If it is different, do not run the file and open an issue.

The in-app updater checks the SHA-256 of a new installer by itself before installing it.

After installing

  1. The first-run wizard asks how to translate: online without a key, an LLM with your key, or offline (downloads the local model).
  2. Press Ctrl+Shift+R and drag over any text. Settings open with Ctrl+Shift+O.
  3. Uninstalling keeps %APPDATA%\translator-overlay\ (settings, history, downloaded models); delete that folder to remove everything.

Read the documentation or go back to the home page.
