# Baseline: NLLB-200-distilled-600M (int8, no fine-tuning)

Reference point for comparison after fine-tuning. Re-run this same script with the same `--seed` after fine-tuning.

## Status (2026-09-23)

**Preliminary: do not use as a comparison point.**

- The baseline was computed on **6 pairs** and is not statistically significant: the translation history consists almost entirely of test strings (`Hello world`, `Unique Domain Test String 123`, etc.), not real game chat.
- Corpus chrF is **29.75** with a per-sentence spread of **0.0 – 96.8**: the score is driven by a couple of individual sentences, not by model quality.
- One pair failed because of a langid error: the source was detected as `la` (Latin) instead of its real language, and `la` is not supported by the local NLLB model (see "Failed pairs").

## ⚠ Sample size limitation

Only **6** pairs were evaluated instead of the requested 30: that is all the translation history contains. On a sample this small chrF is not statistically significant: a single sentence moves the corpus score by tens of points.

For the baseline to be meaningful, accumulate real history (use the app with the API backend), then re-run:

```bash
python scripts/export_history_dataset.py
python scripts/baseline_eval_nllb.py --seed 13
```

Until then, rely on the "Examples for manual review" section and on `scripts/test_nllb_translation.py`, whose phrases are chosen for the target domain (game chat).
