# Game-chat phrases for the NLLB abbreviation fine-tune (stage 2.1).
#
# Format
#   ## <abbr> | <mode> | <expansion>
#   <phrase with the abbreviation> => <same phrase, abbreviation expanded>
#
# mode = translate : the abbreviation is expanded in the "full" phrase and the
#                    translation carries its meaning.
# mode = keep      : a gaming term that players write as is in every target
#                    language; the translation must keep it verbatim, so a line
#                    without "=>" means full == short.
#
# Sources: willwade/txt-sms-abbreviations (Apache-2.0) with gaming expansions
# fixed by hand (gg, op, cc, dm, ign, ks, nt, pve ...), plus gaming abbreviations
# missing from it (marked "added").
